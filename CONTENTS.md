# What is in this folder

The code plus every output of the NTSB build of 10 November 2026. Everything below except the code and `data/`
inputs can be regenerated with `./build_all.sh` (the step that writes it is given); it is included so the results
can be inspected without rebuilding.

| Folder | What it holds | Size | Regenerated by |
|---|---|---|---|
| `taxground/`, `tools/`, `db/`, `prompts/`, `tests/` | the pipeline code, tools, schema, prompt, unit tests | < 1 MB | — (source) |
| `build_all.sh`, `setup.sh`, `docker-compose.yml`, `README.md` | the one-command build, setup and documentation | — | — (source) |
| `data/trial`, `data/sample_b`, `data/combined` | synthetic answer-key sets used by step 0 | < 1 MB | — (inputs) |
| `data/discovery/ntsb_batch_d.json` | the 16 candidates drafted from report clusters | — | — (input, drafted once) |
| `data/eccairs_events.json` | the 809 ECCAIRS 1.3.0.12 attribute-390 events parsed from the PDF | 0.4 MB | step 3 |
| `data/ntsb/` | ingested NTSB data: 27,895 reports (`sample_reports.json`), 33 parents, 548 definitions, 53 candidates, occurrence map | 225 MB | steps 2, 3, 6 |
| `out_ntsb/run-ntsb-*` | the five section-chunk NTSB runs, oldest first (see the run table below); each holds results, SSSOM links, criteria cards, taxonomy, changelog, gate, review pack and a snapshot of its inputs | 229 MB each | step 7 (and 8, the twin) |
| `out_ntsb/release-v0.2-test/` | the trial release made by the build (approver marked "not an SME") | 0.2 MB | step 11 |
| `out_ntsb/test-20261110T192903-v0.2-test/` | 200 recent reports scored against that release, with revision prompts | 0.1 MB | step 12 |
| `out_ntsb_rep/run-ntsb-*` | the two whole-report runs used for comparison | 225–229 MB each | step 7 with `UNITS=report` |
| `out/` | synthetic answer-key and demo runs | 6 MB | step 0, `demo.sh` |
| `derived/run-ntsb-20261110T192033918/` | the derived-data folder: `derived_workbook.xlsx` (32 tabs), one CSV per tab, `lineage.json` | 12 MB | step 15 |
| `viewer/index.html`, `viewer/data/` | viewer source and the data it was exported with (run, corpus, technique measurements) | 35 MB | steps 13, 14 |
| `viewer/dist/index.html` | the self-contained viewer page (open it in a browser, no server) | 11 MB | step 14 |

Every run folder's `inputs/sample_reports.json` is the same file (sha256 `d4d63e0f83d0…`), the same as
`data/ntsb/sample_reports.json`; it is kept in each run because report testing rebuilds a version's embedder from its
own recorded inputs.

Not included: the raw NTSB `avall.zip` / `avall.mdb` and its CSV export (download them from NTSB CAROL; step 1 makes
the CSVs), the ECCAIRS PDF, and the Postgres database (step 7 rebuilds the working set; SME decisions and releases live
there, so the trial release v0.2-test exists only as the files above until it is re-made).
